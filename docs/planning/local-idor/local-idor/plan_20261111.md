## Phase 1: Scan and CLI local integration

**Files:** `src/pry/probe/client.py`, `src/pry/probe/scan.py`, `src/pry/cli.py`,
`tests/probe/test_client.py`, `tests/probe/test_scan.py`,
`tests/probe/test_local_idor_cli.py`

**Steps (TDD):**
1. `ProbeClient.run_idor()` execs the sidecar; parses a `ProbeResult`; failures UNVERIFIED.
2. `scan_local(..., idor_config=None)`:
   - Write a 0600 temp config from the `IdorConfig`; start the sidecar with the config mount;
     run floor/unauth/SSRF/rate-limit/IDOR in order; parse; append; remove the temp in
     `finally`.
   - No config → no mount/result.
   - EXPOSED IDOR is signed by the shared finalize path.
3. CLI local `--idor-config`: load/validate; pass to `scan_local`; remove
   `IDOR_REQUIRES_LIVE`; URL behavior unchanged; no `--confirm` needed.
4. Tests: temp config 0600/removed; mount; result; signed; no credentials/config/temp path in
   outputs; no config; CLI.
5. Run the full suite.

**Commit:** `feat(cli): run configured idor checks locally`

## Edge Cases

| Case | Behavior |
|---|---|
| Local config 0600 | IDOR runs |
| Local config 0644/invalid | exit 2 |
| No config | no IDOR |
| A→B 200 | EXPOSED |
| A→B 403 | NOT_REPRODUCED |
| B→B 403 | UNVERIFIED |
| Temp cleanup | removed on success/failure |
| Credentials leak | never |
| URL + config | live path unchanged |
| Default suite | offline; Docker opt-in |

## Definition of Done

- Local IDOR EXPOSED signed/report; credentials absent; temp removed.
- Docs state local-only, 0600, read-only mount, no discovery, no secure.
