## Phase 0: Config loader and probe

**Files:** `src/pry/probe/idor.py`, `tests/probe/test_idor.py`

**Steps (TDD):**
1. Tests:
   - `load_idor_config`: 0600 required; 0644/group bits refused; missing file/JSON/fields
     refused; absolute/protocol-relative/whitespace object paths refused; forbidden headers
     (`Host`, `Content-Length`, `Transfer-Encoding`), newline/control values refused; valid
     config returns the dataclass.
   - `probe_idor` with a fake fetch:
     - controls A/B 200 JSON + cross 200 JSON → EXPOSED.
     - cross 403 → NOT_REPRODUCED.
     - A control 401 or B control 403 → UNVERIFIED `IDOR_CONTROL_FAILED`; cross not used.
     - cross 500/transport → UNVERIFIED.
     - redaction: Cookie/Authorization/Set-Cookie/X-Api-Key values replaced with
       `[redacted]`; request uses real headers (fake fetch sees them), result does not.
     - evidence names both objects and the control statuses; no config path.
2. Implement `idor.py`:
   - `IdorConfig(headers_a, headers_b, object_a, object_b)`.
   - `load_idor_config(path)`; `stat.S_IMODE`; `validate_endpoints` for paths; header checks.
   - `probe_idor(base_url, config, fetch=None)`; `urllib_fetch` default; `_is_json_ok`;
     `_redact_headers`; result dict matching `ProbeResult`.
3. Run tests.

**Commit:** `feat(probe): add a configured idor probe`

## Phase 1: Live scan and CLI

**Files:** `src/pry/probe/live.py`, `src/pry/cli.py`,
`tests/probe/test_live.py`, `tests/probe/test_live_cli.py`

**Steps (TDD):**
1. `scan_live(..., idor_config=None)`: append the IDOR result after the default/unauth
   probes; token validated before any probe.
2. CLI: `--idor-config FILE` on scan; URL path loads/validates and passes it; local path with

   the result.
3. Tests: live scan appends the result and proof/report; token gate; CLI forwarding; local
   rejection; invalid config; no config no IDOR; no credential/token/config-path leak.
4. Run the full suite.

**Commit:** `feat(cli): run configured idor checks live`

## Edge Cases

| Case | Behavior |
|---|---|
| Config 0644 | exit 2, no request |
| Absolute/protocol-relative object | exit 2 |
| Header injection/newline | exit 2 |
| A/B control fails | UNVERIFIED `IDOR_CONTROL_FAILED` |
| Cross 2xx JSON | EXPOSED |
| Cross 401/403/404 | NOT_REPRODUCED |
| Cross 5xx/transport | UNVERIFIED |
| Local path + flag | exit 2 `IDOR_REQUIRES_LIVE` |
| Credentials in output | never; redacted |
| Config path in output | never |
| No flag | existing probes only |
| Default suite | offline; loopback only |
