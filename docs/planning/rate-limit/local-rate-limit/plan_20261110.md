## Phase 0: Sidecar probe and observation model

**Files:** `src/pry/probe/sidecar.py`, `src/pry/probe/rate_limit.py`,
`tests/probe/test_rate_limit.py`, `tests/probe/test_sidecar.py`

**Steps (TDD):**
1. Tests:
   - `probe_rate_limit(base_url, path, count, fetch, sleep)` with a fake fetch:
     - all 200 → `OBSERVED`, count/statuses recorded.
     - 429 at request 4 → `THROTTLED`, stopped, statuses end at 429.
     - 503/`Retry-After` → THROTTLED.
     - 401/404/500 → `UNVERIFIED` control failed.
     - transport error → `UNVERIFIED`.
     - count 1/20; no auth/cookies; body cap; no sleep in tests.
   - `main(["rate_limit", base, path, "10"])` prints JSON; bad argv exits 2.
   - `validate_rate_limit`: path-only, no query/fragment, count 1–20; invalid causes.
   - `parse_rate_limit_result`: valid statuses; malformed → UNVERIFIED; no verdict/proof.
2. Implement:
   - `sidecar.py`: `probe_rate_limit`, `rate_limit` branch in `main`.
   - `rate_limit.py`: `RateLimitConfig`, `validate_rate_limit`, `parse_rate_limit_result`.
3. Run tests.

**Commit:** `feat(probe): add the local rate-limit observation`

## Phase 1: Scan and CLI integration

**Files:** `src/pry/probe/scan.py`, `src/pry/probe/results.py`,
`src/pry/probe/client.py`, `src/pry/cli.py`,
`tests/probe/test_scan_rate_limit.py`, `tests/probe/test_rate_limit_cli.py`

**Steps (TDD):**
1. `ProbeClient.run_rate_limit(path, count)` execs the sidecar and returns the observation
   dict (UNVERIFIED on exec/timeout/invalid).
2. `ScanOutcome`/`ScanResult` gain `observations`; `finalize_results` writes them; proof
   signing remains EXPOSED-only; `scan_local` accepts `rate_limit_config`.
3. CLI:
   - `--rate-limit-endpoint`, `--rate-limit-count` (default 10).
   - Level 1 + confirm; at least one of SSRF/rate-limit; both allowed.
   - Level 0/URL/level 2/invalid count/partial config → exit 2 with named causes.
   - Human/JSON output includes observations; report includes them; exit code unaffected.
4. Tests: scan observations, no proof, results.json schema, CLI matrix, output.
5. Run the full suite.

**Commit:** `feat(cli): run local rate-limit observations`
