## Phase 0: Config, sidecar write probe, mount

**Files:** `src/pry/probe/write.py`, `src/pry/probe/sidecar.py`,
`src/pry/intake/docker.py`, `tests/probe/test_write.py`, `tests/probe/test_sidecar.py`,
`tests/intake/test_docker.py`

**Steps (TDD):**
1. Tests:
   - `load_write_config` accepts a 0600 JSON config with POST/PUT/PATCH, path-only endpoints,
     a `{{marker}}` body, and a verification path; rejects 0644/missing/invalid/absolute paths,
     DELETE, missing marker, oversized body, query/fragment.
   - `probe_write(base_url, config, fetch)` sends the write with the marker, then the verify
     GET; EXPOSED only when both 2xx and the marker is in the verify body; 401/403/404 or
     missing marker NOT_REPRODUCED; 5xx/transport UNVERIFIED; same-origin checks; no auth.
   - The result nests `{"request": ..., "response": ...}` under `response["verification"]`.
   - `main(["write", base, config_path])` prints JSON; bad argv 2.
   - `start_sidecar(..., write_config_path=path)` mounts
     `-v <path>:/pry-config/write.json:ro`; no config → no mount.
2. Implement `write.py`, `probe_write`, main branch, Docker mount.
3. Run tests.

**Commit:** `feat(probe): confirm a declared local write`

## Edge Cases

| Case | Behavior |
|---|---|
| Write 201 + verify 200 marker | EXPOSED |
| Write 401/403/404 | NOT_REPRODUCED |
| Write 2xx, marker absent | NOT_REPRODUCED |
| Write 5xx/transport | UNVERIFIED |
| Verify transport | UNVERIFIED |
| Live URL + config | exit 2, no request |
| Config 0644/invalid | exit 2, no scan |
| Temp cleanup | removed on success/failure |
| Default scan | unchanged |

## Definition of Done

- AT1–AT10 pass; default suite offline; Docker integration passes.
- Local write EXPOSED signed/reported; verification pair captured; temp removed.
- Docs state local-only, live writes deferred, no secure.
