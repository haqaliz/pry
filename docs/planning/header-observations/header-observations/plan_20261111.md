## Edge Cases

| Case | Behavior |
|---|---|
| No flag | observations unchanged |
| Missing headers | OBSERVED with list |
| All present | OBSERVED with empty missing |
| HTTP vs HTTPS | HSTS only HTTPS |
| Transport | UNVERIFIED |
| Report | escaped lists; no proof |
| Exit code | unchanged |
| Default suite | offline; Docker opt-in |
