## Phase 0: Live scan core

**Goal:** `scan_live` validates P1, runs the shared probes, and finalizes results.

**Files:** `src/pry/probe/live.py`, `src/pry/probe/scan.py`,
`tests/probe/test_live.py`

**Steps (TDD):**
1. Tests:
   - Missing/invalid token → `OwnershipError`, a sentinel fetch never called.
   - Valid token + fake probes → 3 results; declared endpoints append unauth; EXPOSED signed;
     `snapshot.json`/`results.json`/proofs/corpus written.
   - Live snapshot: kind `live`, path/url = origin, ownership proof type, no git/image/token.
   - `scan_live` does no Docker/network when probes are injected.
2. Implement:
   - `scan_live(url, token, *, endpoints=None, out=None)`.
   - Validate `normalize_target` + `TokenSigner.validate` before any probe/fetch.
   - Build/write the live snapshot; run `probe_cors/errors/secrets/unauth` in-process;
     convert to `ProbeResult`.
   - Extract/share `finalize_results` with `scan_local` (sign, summarize, results.json,
     corpus) so both paths use one implementation.
3. Run tests.

**Commit:** `feat(probe): scan a live url read-only`

## Phase 1: CLI URL path

**Goal:** `pry scan URL --token` runs the live path, with report/JSON/endpoint.

**Files:** `src/pry/cli.py`, `tests/probe/test_live_cli.py`,
`tests/test_cli.py`, `tests/probe/test_cli.py`

**Steps (TDD):**
1. Tests:
   - Valid token → `scan_live` called; results printed; exit 1 on EXPOSED, 0 clean.
   - Missing/invalid token → exit 2, `scan_live` not called / no fetch.
   - `--report` writes and prints the report path; `--json` includes report and results.
   - `--endpoint` forwarded; invalid endpoint → exit 2.
   - Local path behavior unchanged; P1/P2/P3 tests still pass.
2. Implement the URL branch; keep local `scan_local` branch.
3. Run the full suite.

**Commit:** `feat(cli): run live read-only scans`

## Phase 3: Loopback integration and docs

**Goal:** Real probes against a local server; docs truth.

**Files:** `tests/probe/test_live_integration.py`, `README.md`, `CLAUDE.md`,
`docs/technical/ARCHITECTURE.md`, `docs/technical/CAPABILITY_ROADMAP.md`,
`docs/ROADMAP.md`, `ETHICS.md`, `tests/test_docs_truth.py`

**Steps:**

   - Docs truth assertions.
3. Final: 3.9.6 suite, Docker suite, build.

**Commit:** `test(probe): cover live scans against a loopback server` and
`docs: record live read-only scans`

## Edge Cases

| Case | Behavior |
|---|---|
| Missing/invalid token | exit 2, no request |
| Token for another origin | exit 2, no request |
| Token in output | never |
| 3xx redirect | not followed |
| 4xx/5xx | probe verdict per rules |
| Live snapshot | kind live, no git/image/container |
| Report host | `urlsplit(...).hostname` |
| Declared endpoint | path-only, forwarded |
| Level 1/2 | exit 2, not implemented |
| Default suite | offline; loopback only |

- Missing/invalid token sends no request.
- Docs state read-only, P1-gated, 4–6 GETs, no secure.
