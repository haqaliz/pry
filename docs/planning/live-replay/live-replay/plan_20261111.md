## Phase 0: Replay module and CLI

**Files:** `src/pry/probe/replay.py`, `src/pry/cli.py`,
`tests/probe/test_replay.py`, `tests/probe/test_replay_cli.py`

**Steps (TDD):**
1. Tests:
   - Valid live GET proof + token + same status → MATCH; different status → MISMATCH;
     transport → UNVERIFIED.
   - Invalid shape, non-live target, non-GET, foreign URL, missing/wrong token → ReplayError
     before any fetch.
   - Header allowlist: only `user-agent`/`accept`; no `authorization`/`cookie`.
   - No redirects; 4 KiB cap; recorded/replay statuses in the result.
   - CLI exit 0/1/2 and JSON.

3. Run tests.

## Edge Cases

| Case | Behavior |
|---|---|
| Same status | MATCH, exit 0 |
| Different status | MISMATCH, exit 1 |
| Transport | UNVERIFIED, exit 2 |
| Invalid bundle | exit 2, no request |
| Local/non-GET | exit 2, no request |
| Foreign URL | exit 2, no request |
| Wrong token | exit 2, no request |
| Auth/cookie headers | never sent |
| Redirect | not followed |

## Definition of Done

- AT1–AT9 pass; default suite offline except loopback; Docker suite passes.
- Replay is status-only, token-gated, GET-only; docs say so.
