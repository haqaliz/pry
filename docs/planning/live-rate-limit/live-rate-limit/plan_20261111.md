`src/pry/probe/live.py`, `tests/probe/test_rate_limit.py`, `tests/probe/test_live.py`

**Steps (TDD):**
1. Tests:
   - `validate_rate_limit(..., max_count=5)` rejects 6; local default still 20.
   - `probe_rate_limit(..., spacing=0.5)` uses 0.5 between requests; stops on 429/503/
     `Retry-After`.

## Edge Cases

| Case | Behavior |
|---|---|
| Live count 6 | exit 2, no request |
| No confirm | exit 2, no request |
| No endpoint | exit 2, no request |
| SSRF on URL | exit 2, no request |
| 429/503/Retry-After | THROTTLED, stop |
| All 2xx | OBSERVED with count/statuses |
| Transport failure | UNVERIFIED |
| No flags | no observation |
| Exit code | unchanged by observation |
