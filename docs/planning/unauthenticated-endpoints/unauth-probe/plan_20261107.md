## Phase 0: Sidecar `unauth` probe

**Goal:** One in-container function that sends an unauthenticated GET to a declared path.

**Files:** `src/pry/probe/sidecar.py`, `tests/probe/test_sidecar.py`

**Steps (TDD):**
1. Tests with the fake fetch:
   - 200 JSON + no auth headers → EXPOSED; request has only `User-Agent`.
   - 401/403/404 → NOT_REPRODUCED.
   - 200 HTML → NOT_REPRODUCED.
   - 500 → UNVERIFIED.
   - `http://evil.invalid`, `//evil.invalid`, whitespace, empty → refused before fetch.
   - Body cap; lowercase headers; one result per call.
2. Implement `probe_unauth(base_url, path, fetch=None)`:
   - Validate path-only; raise/return UNVERIFIED with `INVALID_ENDPOINT` if not.
   - `GET base_url + path`, `User-Agent: pry/0.1`, no auth/cookies.
   - 2xx + JSON content type or body starting with `{`/`[` and non-empty → EXPOSED.
   - 2xx HTML → NOT_REPRODUCED; 401/403/404 → NOT_REPRODUCED; 5xx → UNVERIFIED.
   - Evidence quotes the path and status.
3. Extend `main` to accept `unauth` plus a fourth argv element (the path); other probes
   keep two args.
4. Run tests.

**Commit:** `feat(probe): add the unauthenticated endpoint probe`

## Edge Cases

| Case | Behavior |
|---|---|
| Absolute URL / `//host` / whitespace | `INVALID_ENDPOINT`, exit 2, no request |
| 200 JSON data | `EXPOSED`, no auth/cookie headers |
| 200 HTML login page | `NOT_REPRODUCED` |
| 401/403/404 | `NOT_REPRODUCED` |
| 5xx / transport | `UNVERIFIED` |
| Empty body | `NOT_REPRODUCED` |
| No endpoints | check not run; 3 default results |
| Multiple endpoints | one result each |
| Body > 4 KiB | capped |
