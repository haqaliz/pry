## Edge Cases

| Case | Behavior |
|---|---|
| SQLite header | EXPOSED, excerpt |
| SQL dump | EXPOSED, excerpt |
| HTML 200 | NOT_REPRODUCED |
| 401/403/404 | NOT_REPRODUCED |
| Transport | UNVERIFIED |
| Foreign origin | no match |
| Rows in dump | never stored |
| Default scan | check always runs |
| Default suite | offline; Docker opt-in |

## Definition of Done

- AT1–AT9 pass; default suite offline; Docker integration passes.
- Database files are detected, signed, and reported with an excerpt only.
- Docs state the four paths, the excerpt policy, and deferred provider rules.
