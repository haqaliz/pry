## Phase 1: Error contract and target normalization

**Goal:** One place decides what a valid target is and what a failure is called.

**Prerequisites:** Phase 0.

- Modify: `src/pry/own/__init__.py` exports

**Steps (TDD):**
1. Write `tests/own/test_target.py` covering AT1/AT2:
   - `example.com` → origin `https://example.com`, host `example.com`, scheme `https`,
     port `None`, `is_loopback False`.
   - `https://EXAMPLE.com:443/` → same origin (default port dropped).
   - `https://example.com./app?x=1#f` → same origin (dot stripped, path/query ignored).

   - Rejections raise `OwnershipError` with cause `UNSUPPORTED_TARGET`.
2. Run the tests; they fail.
3. Implement `errors.py`:
   - `OwnershipError(cause, message)`, `str()` = `"CAUSE: message"`.
   - Cause constants: `UNSUPPORTED_TARGET`, `BAD_CHALLENGE`, `NO_METHOD`,
     `UNSUPPORTED_METHOD`, `DNS_RECORD_NOT_FOUND`, `DNS_MISMATCH`, `DNS_ERROR`,
     `WELL_KNOWN_NOT_FOUND`, `WELL_KNOWN_MISMATCH`, `WELL_KNOWN_REDIRECT`,
     `WELL_KNOWN_ERROR`, `INSECURE_TRANSPORT`, `TOKEN_MALFORMED`,
     `TOKEN_BAD_SIGNATURE`, `TOKEN_EXPIRED`, `TOKEN_TARGET_MISMATCH`, `KEY_INVALID`.
4. Implement `target.py`:
   - `@dataclass(frozen=True) Target(origin, scheme, host, port, is_loopback, is_ip)`.
   - `normalize_target(raw: str) -> Target`.

     reject userinfo; lowercase host; strip trailing dot; IDNA-encode; reject empty;
     parse port with `ValueError` → `UNSUPPORTED_TARGET`; drop 80/443 defaults;
     `is_ip` via `ipaddress.ip_address`; `is_loopback` for `localhost`, `127.0.0.1`,
     `::1`, or `ip.is_loopback`; format IPv6 with brackets in `origin`.
   - Properties: `dns_name` (`_pry.<host>`) and `well_known_url`
     (`<origin>/.well-known/pry-ownership.txt`).
5. Run tests.

**Validation:** `uv run pytest tests/own/test_target.py` passes.

## Phase 2: DNS TXT verification

**Goal:** A real TXT lookup decides DNS ownership, with a fake resolver in tests.

   - Fake returns `["other"]` → `DNS_MISMATCH`.
   - Fake returns `[]` → `DNS_RECORD_NOT_FOUND`.
   - Fake raises `TimeoutError` → `DNS_ERROR`.
   - Fake returns a value split into two TXT chunks (`"pry-verify="`, `"<nonce>"`) →

   - IP target `https://127.0.0.1` → `UNSUPPORTED_TARGET`.
2. Run the tests; they fail.
3. Implement `dns.py`:
   - `TxtResolver = Callable[[str], List[str]]`.
   - `default_resolve_txt(name)`: `dns.resolver.resolve(name, "TXT", lifetime=5.0)`;
     catch `NXDOMAIN`/`NoAnswer` → `[]`; catch `Timeout`/other → `DNS_ERROR`; for each
     rdata, `b"".join(rdata.strings).decode("utf-8", "replace")`.
   - `verify_dns(target, challenge, resolve_txt=default_resolve_txt) -> None`:
     reject IP targets; expected `pry-verify=<challenge>`; exact match against any
     stripped answer; empty → not found; mismatch otherwise. Wrap unexpected
     exceptions as `DNS_ERROR`.
4. Run tests.

## Phase 3: Well-known file verification

**Goal:** A real HTTPS fetch of one fixed path decides well-known ownership.

**Prerequisites:** Phase 1.

**Files:**

- Test: `tests/own/test_well_known.py`, `tests/conftest.py`

**Steps (TDD):**
1. Write `tests/conftest.py` with an autouse network guard:
   - Wrap `socket.socket.connect`; allow only loopback destinations; otherwise raise
     `AssertionError("network access to ...")`.
   - Monkeypatch `dns.resolver.resolve` to raise `AssertionError("real DNS lookup")`.
   - Provide an `http_server` fixture: `ThreadingHTTPServer` on `127.0.0.1:0`, routes
     dict, `do_GET`, no logging; yield `(base_url, routes)`; shutdown on teardown.
2. Write `tests/own/test_well_known.py` covering AT5/AT6:
   - Loopback `http://127.0.0.1:<port>` + 200 exact body → verified.
   - 404 → `WELL_KNOWN_NOT_FOUND`.
   - 200 wrong body → `WELL_KNOWN_MISMATCH`.
   - Injected fetch returns `final_url` on another host → `WELL_KNOWN_REDIRECT`.
   - Real fetch follows a same-origin redirect to the exact path → verified; a redirect
     to a different port → `WELL_KNOWN_REDIRECT`.
   - `http://example.com` (non-loopback) → `INSECURE_TRANSPORT`.
   - Injected fetch raises `TimeoutError` → `WELL_KNOWN_ERROR`.
   - Body larger than 4 KiB → `WELL_KNOWN_ERROR` (test the default fetch with the local
     server).
3. Run the tests; they fail.
4. Implement `well_known.py`:
   - `FetchResult(status, final_url, body)`.
   - `default_fetch(url)`: build an opener whose redirect handler rejects a different
     origin (scheme/host/port) with `WELL_KNOWN_REDIRECT`; timeout 5s; read at most
     4097 bytes; map `HTTPError` to `FetchResult(code, url, b"")`; map other errors to
     `WELL_KNOWN_ERROR`.
   - `verify_well_known(target, challenge, fetch=default_fetch)`: reject non-HTTPS
     non-loopback; expected bytes `pry-verify=<challenge>`; reject final URL whose
     origin differs; 404 → not found; non-200 → error; `body.strip() != expected` →
     mismatch.
5. Run tests.

**Validation:** `uv run pytest tests/own/test_well_known.py` passes and the network guard

## Phase 4: Signed ownership tokens

**Goal:** Verification produces a token that cannot be forged, replayed on another
target, or used after expiry.

**Prerequisites:** Phase 1.

**Files:**
- Create: `src/pry/own/tokens.py`
- Test: `tests/own/test_tokens.py`

**Steps (TDD):**
1. Write `tests/own/test_tokens.py` covering AT7/AT8:
   - Issue with a `tmp_path` key, validate for the same target → returns token with
     `target`, `proof_type`, `issued_at`, `expires_at`.
   - Key file exists, length 32, mode `0600`; a second signer with the same path reads
     it and validates.
   - Tamper one character of the signature → `TOKEN_BAD_SIGNATURE`.
   - Tamper the payload → `TOKEN_BAD_SIGNATURE`.
   - Issue at `now=0`, validate at `now=86401` → `TOKEN_EXPIRED`.
   - Validate against `https://other.example` → `TOKEN_TARGET_MISMATCH`.
   - Two different key paths → `TOKEN_BAD_SIGNATURE`.
   - `"garbage"`, `"pry1.a.b"`, wrong prefix → `TOKEN_MALFORMED`.
   - A key file with 16 bytes → `KEY_INVALID`.
2. Run the tests; they fail.
3. Implement `tokens.py`:
   - `OwnershipToken(target, proof_type, issued_at, expires_at)`.
   - `TokenSigner(key_path=None)`: default `$PRY_KEY_FILE` or `~/.pry/ownership.key`.
   - Key load/create: `mkdir(parents=True, mode=0o700, exist_ok=True)`;
     `os.open(..., O_CREAT|O_EXCL|O_WRONLY, 0o600)`, write `secrets.token_bytes(32)`,
     `os.chmod(path, 0o600)`; `FileExistsError` → read; length != 32 → `KEY_INVALID`.
   - `issue(target, proof_type, now=None)`: canonical JSON
     `{"v":1,"target":..., "proof":..., "iat":..., "exp":...}`;
     `hmac.new(key, payload, sha256)`; `pry1.<b64u(payload)>.<b64u(sig)>`.
   - `validate(token, target, now=None)`: split, decode, verify signature in constant
     time, parse, check `v==1`, target equality, expiry, `exp > iat`; map each failure
     to the cause constants.
4. Run tests.

**Validation:** `uv run pytest tests/own/test_tokens.py` passes.

**Commit:** `feat(own): issue and validate signed ownership tokens`

## Testing Strategy

- **Unit:** normalization (AT1/AT2), DNS policy (AT3/AT4), well-known policy
  (AT5/AT6), token format and failures (AT7/AT8), orchestration.
- **CLI integration:** call `main([...])` directly; monkeypatch only the boundary
  (`verify_target` / `run_scan`). Assert exit codes, output text, and whether the
  post-gate function ran.
- **Offline guarantee:** autouse guard blocks non-loopback `socket.connect` and all
  real `dns.resolver.resolve` calls. The local HTTP server uses loopback only.
- **Manual:** `uv run pry --help`, the invalid-token scan, and the owner-controlled
  domain verification. Never a third-party target.

Test command: `uv run pytest -q`. Expected: all green, no network warnings.

## Edge Cases & Error Handling

| Case | Behavior |
|---|---|
| Bare host | Default `https://` |
| Trailing dot / uppercase host | Normalized |
| Unicode host | IDNA-encoded; failure → `UNSUPPORTED_TARGET` |
| IPv6 literal | Brackets in origin; `::1` is loopback |
| IP target for DNS | `UNSUPPORTED_TARGET` |
| Non-http(s) scheme | `UNSUPPORTED_TARGET` |
| Userinfo in URL | `UNSUPPORTED_TARGET` |
| Invalid port / out of range | `UNSUPPORTED_TARGET` |
| TXT split into chunks | Concatenate; compare |
| Multiple TXT records | Any exact match passes |
| TXT NXDOMAIN / no answer | `DNS_RECORD_NOT_FOUND` |
| DNS timeout | `DNS_ERROR` |
| Well-known 404 | `WELL_KNOWN_NOT_FOUND` |
| Well-known wrong body | `WELL_KNOWN_MISMATCH` |
| Cross-origin redirect | `WELL_KNOWN_REDIRECT` |
| HTTP non-loopback | `INSECURE_TRANSPORT` |
| TLS failure / timeout | `WELL_KNOWN_ERROR` |
| Body > 4 KiB | `WELL_KNOWN_ERROR` |
| Key file wrong size | `KEY_INVALID`; never regenerate silently |
| Token malformed / bad signature / expired / wrong target | Matching cause; exit 2 |
| Both token flags / neither | Exit 2, no scan |
| Level 1/2 | Exit 2, `INTENSITY_INSUFFICIENT` |
| Valid token, no probes | Exit 1, `UNVERIFIED`, never 0 |

## Agent Execution Notes

- **Test first, then code.** Each phase's test file is written and run red before the
  implementation. Do not batch phases.
- **Commit per phase.** Run `git status`; never add `.venv`, `__pycache__`, or keys.
- **Checkpoints for human review:** after Phase 3 (network policy), after Phase 4
  (token format), and after Phase 6 (CLI gate). These are the security-sensitive
  surfaces.
- **Likely debugging:** `urllib` redirect behavior, dnspython TXT chunk joining on
  2.7, IPv6 origin formatting, and the key file race (`O_EXCL`).
- **Ask before proceeding if:** a test requires a real network call, the `uv sync`
  fails for lack of network, or a design detail contradicts the PRD.
- **Do not:** add probes, add OAuth, touch the unmerged P2/P3 worktree, or use the word
  "secure" in output or docs.
