## Phase 0: Corpus

**Goal:** Append each finding as a JSONL record, locally and safely.

**Files:** `src/pry/report/__init__.py`, `src/pry/report/corpus.py`,
`tests/report/__init__.py`, `tests/report/test_corpus.py`

**Steps (TDD):**
1. Tests: append two records → two JSON lines; read back; 0600 dir/file; `PRY_CORPUS`
   override; a write error raises `ReportError(REPORT_FAILED)`.
2. Implement:
   - `ReportError(cause, message)`; causes `REPORT_MISSING`, `REPORT_MALFORMED`,
     `REPORT_FAILED`.
   - `corpus_path()`, `append_findings(records)`, `read_findings()`.
   - JSON sorted keys; one line per record; append mode.
3. Run tests.

**Commit:** `feat(report): bank findings in a local corpus`

## Phase 1: Report builder and HTML renderer

**Goal:** Load a run dir, verify proofs, render safe self-contained HTML.

**Files:** `src/pry/report/report.py`, `tests/report/test_report.py`

**Steps (TDD):**
1. Tests with a temp run dir:
   - `load_run` reads snapshot/results; counts; proof fingerprint + valid.
   - Tampered proof → valid False + reason; missing proof → unsigned.
   - Missing/invalid files → `REPORT_MISSING`/`REPORT_MALFORMED`.
   - `render_html` contains target basename/kind/commit, counts, evidence, request/response,
     fingerprint, no-secure/deferred note.
   - `<script>alert(1)</script>` in evidence/body/headers is escaped.
   - No `<script>` tag, no external `src=`/`href=` assets.
   - `write_report` default `run_dir/report.html`, 0600, atomic; `--out` override.
2. Implement:
   - `Report` dataclass; `load_run`; `render_html`; `write_report`.
   - Resolve proof paths: absolute, else `run_dir / proof`, else cwd.
   - Inline CSS; no JS; `html.escape` all dynamic values.
3. Run tests.

**Commit:** `feat(report): render a safe local findings report`

## Phase 2: CLI report and scan integration

**Goal:** `pry report RUN_DIR` and `pry scan --report`; corpus warnings.

**Files:** `src/pry/probe/scan.py`, `src/pry/cli.py`,
`tests/probe/test_scan.py`, `tests/report/test_cli.py`

**Steps (TDD):**
1. `ScanOutcome` gains `corpus_error: Optional[str] = None`; `scan_local` appends corpus
   records after results.json; a `ReportError` sets `corpus_error` and does not fail the scan.
2. CLI:
   - `report` subparser: `run_dir`, `--out`, `--json`; prints the path; exit 0/1.
   - `scan --report`: after a local scan, write the report and print `Report: <path>`;
     report failure exits 2; scan verdict/exit preserved otherwise.
   - `_scan_target_path` prints `Warning: corpus not written: ...` to stderr when
     `corpus_error`.
3. Tests: corpus warning, report command, scan --report, missing run dir, JSON metadata.
4. Run the full suite.

**Commit:** `feat(cli): add local report generation`

## Edge Cases

| Case | Behavior |
|---|---|
| Missing snapshot/results | `REPORT_MISSING`, exit 1 |
| Invalid JSON | `REPORT_MALFORMED`, exit 1 |
| Tampered proof | INVALID in report |
| No proof on EXPOSED | UNSIGNED in report |
| Script/attribute injection | escaped |
| Missing proof path | INVALID/UNSIGNED, no crash |
| Corpus write failure | warning, scan succeeds |
| Report write failure | exit 2 for scan --report; report command 1 |
| Safe run | zero EXPOSED, no "secure" |
