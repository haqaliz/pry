## Phase 0: Dependency and proof bundle module

**Goal:** Sign and verify a finding payload with Ed25519; keys and bundles are safe.

**Files:** `pyproject.toml`, `uv.lock`, `src/pry/proof/__init__.py`,
`src/pry/proof/bundle.py`, `tests/proof/__init__.py`, `tests/proof/test_bundle.py`

**Steps (TDD):**
1. `uv add "cryptography>=42,<47"`; confirm `uv run python -c "import cryptography"`.
2. Tests:
   - Sign a finding → bundle has version/created_at/bundle_id/payload/signature; no private
     key; verify returns VALID and the same fingerprint.
   - Tampered payload, signature, public key → INVALID with a named cause.
   - Wrong `--fingerprint`/expected fingerprint → INVALID.
   - Malformed bundle/missing fields/invalid base64 → INVALID.
   - Key file 32 bytes, 0600; bundle 0600; two signers produce different fingerprints.
   - Canonical payload: same dict order → same bundle_id; changed value → different.
   - Copied bundle verifies without the original run dir.
3. Implement `bundle.py`:
   - `ProofError(cause, message)`; causes `PROOF_FAILED`, `PROOF_KEY_INVALID`,
     `PROOF_MALFORMED`, `PROOF_FINGERPRINT_MISMATCH`, `PROOF_SIGNATURE_INVALID`.
   - `canonical_bytes(payload)`, `public_fingerprint(public_key)`, `bundle_id`.
   - `ProofSigner(key_path=None, created_at=None)`; key load/create; `sign(payload) -> dict`.
   - `build_bundle(target, finding, signer=None) -> dict`.
   - `write_bundle(run_dir, bundle) -> Path` (proofs/<bundle_id>.json, 0600, atomic).
   - `load_bundle(path) -> dict`; `verify_bundle(bundle, expected_fingerprint=None) ->
     (payload, fingerprint)` or raises.
4. Run tests.

**Commit:** `feat(proof): sign findings with ed25519`

## Phase 1: Scan writes signed bundles

**Goal:** Every EXPOSED local finding gets a bundle; other verdicts do not.

**Files:** `src/pry/probe/results.py`, `src/pry/probe/scan.py`,
`tests/probe/test_results.py`, `tests/probe/test_scan.py`

**Steps (TDD):**
1. Tests:
   - `ProbeResult` accepts an optional `proof` field; existing payloads still parse.
   - `scan_local` with a fake intake/results and a tmp `PRY_PROOF_KEY` writes one bundle
     per EXPOSED, sets `result.proof`, and verifies each bundle.
   - NOT_REPRODUCED/UNVERIFIED → no bundle.
   - Signing failure → `PROOF_FAILED`, no results.json (exit 2 at CLI).
   - `results.json` includes the proof paths.
2. Implement:
   - Add `proof: Optional[str] = None` to `ProbeResult`.
   - In `scan_local`, after intake and before `results.json`, build the target snapshot
     dict, sign each EXPOSED result, write the bundle, replace the result with
     `proof=<path>`.
   - Use `ProofSigner()` with `PRY_PROOF_KEY` for tests.
3. Run tests.

**Commit:** `feat(scan): write a signed bundle for every exposed finding`

## Phase 2: CLI verify-proof

**Goal:** A third party can verify a bundle without the run directory.

**Files:** `src/pry/cli.py`, `tests/proof/test_cli.py`

**Steps (TDD):**
1. Tests:
   - `main(["verify-proof", path])` valid → 0, prints `VALID`, fingerprint, finding.
   - Tampered/malformed/missing file → 1, `INVALID`.
   - `--fingerprint` matching → 0; mismatch → 1.

2. Implement the subparser and `cmd_verify_proof`; leave scan/intake/verify-ownership

**Commit:** `feat(cli): add verify-proof`

## Edge Cases

| Case | Behavior |
|---|---|
| Key file missing | Create 32-byte seed, 0600 |
| Key wrong size | `PROOF_KEY_INVALID`, never regenerate |
| Signature/payload tampered | INVALID |
| Public key swapped | INVALID (fingerprint/signature) |
| Wrong expected fingerprint | INVALID |
| Malformed JSON/missing fields | INVALID |
| Copied bundle | VALID without run dir |
| No EXPOSED | zero bundles |
| Signing failure | `PROOF_FAILED`, exit 2, no results.json |
| Private key in bundle | never |
| `--json` verify | status/fingerprint/finding; same exits |

## Agent Notes

- TDD each phase; commit per phase.
- Do not sign NOT_REPRODUCED/UNVERIFIED; do not add P4/live URL.
- The bundle is local and contains the already-redacted result; no raw secrets.
- The signature proves integrity/key possession, not app security. Say so in docs.

## Definition of Done

- AT1–AT13 pass; default suite offline; Docker suite passes.
- Every EXPOSED local finding has a verifiable bundle; safe scan has none.
- `pry verify-proof` works on a copied bundle.
- Docs state the trust model and no "secure" claim.
