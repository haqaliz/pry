## Phase 0: Callback server, SSRF probe, Docker sidecar

**Goal:** A callback sidecar and a probe script that detects a real fetch.

**Files:** `src/pry/probe/callback_server.py`, `src/pry/probe/ssrf_probe.py`,
`src/pry/intake/docker.py`, `tests/probe/test_ssrf_scripts.py`,
`tests/intake/test_docker.py`

**Steps (TDD):**
1. Tests:
   - Callback server logs `{method,path,headers}` to a hits file, 200 response; configurable
     port/hits path.
   - `ssrf_probe.run_probe(app_base, endpoint, parameter, nonce, callback_base, hits_path,
     fetch=None)`:
     - Test app fetches the callback URL → `hit: true`, app response captured.
     - Test app ignores the URL → `hit: false`, cause None, app response captured.
     - App request error → `hit: false`, cause `SSRF_APP_REQUEST_FAILED`.
     - Hit log unreadable → `SSRF_HIT_READ_FAILED`.
     - Parameter URL-encoded; body cap 4 KiB; no credentials.
   - `DockerRunner.start_callback_sidecar(network, name, source_dir)`:
     - `docker run -d --name <name> --network=<network> --network-alias=pry-callback`,
       security flags, `--read-only`, `--tmpfs=/tmp:rw,exec`, `--user`, limits,
       `-v <source_dir>:/pry:ro`, image `python:3.9-slim`, command
       `["python","/pry/callback_server.py"]`; no `-p`, no socket.
2. Implement:
   - `callback_server.py` stdlib: `ThreadingHTTPServer`, hits JSONL, `create_server`,
     `main(--port/--hits)`; default 0.0.0.0:9000 and `/tmp/pry-callback-hits.jsonl`.
   - `ssrf_probe.py` stdlib: `run_probe`, `main`; GET query injection, no redirects, 10s
     app timeout, 5s hit poll, JSON output.
   - `start_callback_sidecar` in `docker.py`.
3. Run tests.

**Commit:** `feat(probe): add the ssrf callback sidecar and probe`

## Phase 1: SSRF model and scan integration

**Goal:** Validate the config, map the probe JSON, and run it inside the sandbox.

**Files:** `src/pry/probe/ssrf.py`, `src/pry/probe/scan.py`,
`tests/probe/test_ssrf.py`, `tests/probe/test_scan_ssrf.py`

**Steps (TDD):**
1. Tests:
   - `SsrfConfig`/`validate_ssrf`: path-only endpoint, token parameter; invalid → `SSRF_CONFIG_INVALID`.
   - `parse_ssrf_result`: hit → EXPOSED (request=app request, response=callback hit);
     no hit + app response → NOT_REPRODUCED; app/transport error → UNVERIFIED; hit read
     error → UNVERIFIED; malformed payload → UNVERIFIED; no credentials.
   - `scan_local(..., level=1, ssrf_config=...)` with a fake Docker:
     - Starts the callback sidecar on the same network; execs the probe script with the
       app base/endpoint/parameter/nonce/callback base; appends the result; removes the
       callback sidecar.
     - No SSRF config → no callback sidecar, existing results unchanged.
     - Callback/probe failure → UNVERIFIED result, scan continues; cleanup.
     - EXPOSED SSRF is signed in results/proofs.
2. Implement:
   - `ssrf.py`: validation, nonce, `parse_ssrf_result`, `redact_headers` for callback/app
     response headers.
   - `scan.py`: optional `ssrf_config`; in `on_ready`, start callback sidecar, run
     `docker.exec` with `python /pry/ssrf_probe.py`, parse, append, remove in `finally`.
3. Run tests.

**Commit:** `feat(probe): run local ssrf checks in the sandbox`

## Phase 2: CLI Level 1 and confirmation

**Goal:** `--level 1 --confirm --ssrf-*` is explicit and safe.

**Files:** `src/pry/cli.py`, `tests/probe/test_ssrf_cli.py`

**Steps (TDD):**
1. Tests:
   - Local `--level 1 --confirm --ssrf-endpoint /api/fetch --ssrf-parameter url` forwards
     the config; runs floor + SSRF; report/json include it.
   - Missing `--confirm` → exit 2 `CONFIRMATION_REQUIRED`, no scan.
   - Level 1 without SSRF flags → exit 2 `SSRF_CONFIG_REQUIRED`.
   - SSRF flags at level 0 → exit 2 `SSRF_REQUIRES_LEVEL1`.
   - Level 2 → exit 2 `INTENSITY_INSUFFICIENT`.
   - URL + SSRF flags or level 1 → exit 2 `SSRF_REQUIRES_LOCAL_LEVEL1`.
   - Invalid endpoint/parameter → exit 2.
   - Level 0 local path unchanged.
2. Add `--ssrf-endpoint`/`--ssrf-parameter`; enforce the confirmation/config matrix.
3. Run the full suite.

**Commit:** `feat(cli): gate local ssrf behind level 1 confirmation`

## Edge Cases

| Case | Behavior |
|---|---|
| Missing `--confirm` | exit 2, no scan |
| Level 1 no SSRF flags | exit 2 |
| SSRF flags level 0 | exit 2 |
| Level 2 | exit 2 |
| URL + SSRF | exit 2 |
| Invalid endpoint/parameter | exit 2, no request |
| App ignores callback | NOT_REPRODUCED |
| App blocks private URL | NOT_REPRODUCED |
| App request fails | UNVERIFIED |
| Hit log unreadable | UNVERIFIED |
| Callback hit | EXPOSED, signed |
| No config | existing probes only |
| Cleanup | sidecars/network/workspace removed |
