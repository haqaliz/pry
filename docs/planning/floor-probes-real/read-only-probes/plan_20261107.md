# Implementation Plan — Read-Only Floor Probes (P3)

- **Feature:** `floor-probes-real`
- **Aspect:** `read-only-probes`
- **Date:** 2026-11-07
- **PRD:** `../prd.md`
- **Spec:** `spec.md`
- **Execution:** TDD, one phase per commit

## Assumptions

- Python 3.9.6; no 3.10-only syntax.
- Docker 29.9.2 is available; the default suite must not call Docker.
- P2 is merged. `intake()` defaults to `--network=none`; P3 adds an opt-in network mode.
- The app must bind `0.0.0.0` in P3 fixtures so the sidecar can reach it by alias.
- No new Python dependencies. The sidecar uses only the standard library.

## Phase 0: Probe networks and sidecar support in the sandbox

**Goal:** P2 can start an app on an internal network and a probe sidecar, without changing
the default `intake` behavior.

**Files:** `src/pry/intake/docker.py`, `src/pry/intake/sandbox.py`,
`tests/intake/test_docker.py`, `tests/intake/test_sandbox.py`

**Steps (TDD):**
1. Add tests:
   - `DockerRunner.create_network(name)` calls `docker network create --internal name`.
   - `remove_network(name)` tolerates "no such network".
   - `start(..., network="pry-net", alias="app")` uses `--network=pry-net` and
     `--network-alias=app`, no `-p`, and still all security flags.
   - `start(..., network="none")` keeps `--network=none`.
   - `start_sidecar(network, name, script_path)` uses `--network=<network>`,
     `--cap-drop=ALL`, `--security-opt=no-new-privileges`, `--read-only`,
     `--tmpfs=/tmp:rw,exec`, `--user`, limits, `-v <script>:/pry/sidecar.py:ro`,
     `python:3.9-slim`, and a sleep command; no `-p`, no socket.
   - `intake(..., network="pry-net", on_ready=cb)` starts the app with the network/alias,
     records `sandbox.network`, calls `cb` with a `SandboxHandle` after readiness, and still
     cleans up.
   - The callback runs before the success snapshot is written; the default `intake` path is
     untouched.
2. Implement `create_network`, `remove_network`, `start_sidecar`, and the `network`/`alias`
   args on `start`.
3. Add `SandboxHandle(container_id, workspace, port, kind, sandbox_id)` and
   `intake(..., network=None, on_ready=None)`. Default remains `none`.
4. Run `uv run pytest tests/intake -q`.

**Validation:** all P2 tests still pass; new network/sidecar/callback tests pass offline.

**Commit:** `feat(intake): support internal probe networks and sidecars`

## Phase 1: Probe results, redaction, and results.json

**Goal:** One result model with strict verdict fields and secret redaction.

**Files:** `src/pry/probe/__init__.py`, `src/pry/probe/results.py`,
`tests/probe/test_results.py`

**Steps (TDD):**
1. Tests:
   - `ProbeResult` requires probe, verdict, cause, evidence, request, response.
   - `ScanResult` has version, target, results, summary, created_at.
   - `summarize(results)` counts EXPOSED/NOT_REPRODUCED/UNVERIFIED.
   - `redact_secret(text, key)` replaces the value after the key with `[redacted]` and keeps
     the key name.
   - `write_results(run_dir, data)` is atomic, sorted JSON, 0600, `results.json`.
   - A result with an unknown verdict is rejected.
2. Implement `results.py`:
   - `ProbeResult`, `ScanResult`, `summarize`, `redact_secret`, `write_results`.
   - Body excerpt cap constant 4096.
   - Header normalization helper (lowercase keys).
3. Run tests.

**Validation:** `uv run pytest tests/probe/test_results.py` passes.

**Commit:** `feat(probe): define probe results and redaction`

## Phase 2: Read-only probe sidecar

**Goal:** The in-container probe logic for the three checks, testable without Docker.

**Files:** `src/pry/probe/sidecar.py`, `tests/probe/test_sidecar.py`

**Steps (TDD):**
1. Tests use a fake `fetch(method, url, headers) -> Response`:
   - CORS reflected + credentials → EXPOSED; reflected without credentials → NOT_REPRODUCED;
     `*` + credentials → NOT_REPRODUCED; no ACAO → NOT_REPRODUCED.
   - Error page with `Traceback (most recent call last)` and a stack frame → EXPOSED;
     generic 404 → NOT_REPRODUCED; 200 with no error → NOT_REPRODUCED.
   - `/.env` 200 with `DATABASE_URL=...` → EXPOSED, value `[redacted]`; 404 → NOT_REPRODUCED;
     200 with a non-secret config → NOT_REPRODUCED; cross-origin redirect → NOT_REPRODUCED.
   - Body cap 4 KiB; header keys lowercase; request headers include `Origin:
     https://pry.invalid` for CORS and a `User-Agent`.
   - `main()` prints one JSON object for a probe and exits 0; an unknown probe exits 2.
2. Implement:
   - `Response(status, headers, body, final_url)`.
   - `urllib_fetch(method, url, headers)` using `urllib` with redirects disabled, timeout 5,
     body cap 4096.
   - `probe_cors`, `probe_errors`, `probe_secrets` returning `ProbeResult`-shaped dicts.
   - Signature lists: stack/framework/SQL; secret key/value patterns.
   - `main(argv)` dispatches `cors`, `errors`, `secrets` with `base_url`.
3. Run tests.

**Validation:** `uv run pytest tests/probe/test_sidecar.py` passes; no network calls.

**Commit:** `feat(probe): add the read-only probe sidecar`

## Phase 4: Local scan orchestration

**Goal:** One `scan_local(path)` that creates the network, boots the app, starts the sidecar,
runs probes, writes results, and cleans up every time.

**Files:** `src/pry/probe/scan.py`, `tests/probe/test_scan.py`

**Steps (TDD):**
1. Tests with a fake Docker/intake:
   - Creates a `pry-net-*` internal network; passes it to `intake`.
   - `on_ready` starts the sidecar on the same network, runs all probes, removes the sidecar.
   - Writes `results.json` beside the snapshot.
   - Removes the network on success and on intake failure.
   - Any EXPOSED → summary count; no results → UNVERIFIED.
   - Host repo unchanged (reuse P2 behavior).
   - SIGINT/failure cleanup: no sidecar/network/workspace.
2. Implement `scan_local(path, *, out=None, timeout=None, port=None, docker=None)`:
   - Create network; call `intake(..., network=network, on_ready=cb)`; callback starts the
     sidecar, runs probes, removes it in `finally`.
   - After intake, write `results.json`; return `ScanResult` + snapshot.
   - `finally`: remove network.
3. Run tests.

**Validation:** `uv run pytest tests/probe/test_scan.py` passes.

**Commit:** `feat(probe): scan a local repo in the sandbox`

## Testing Strategy

- **Unit, offline:** sidecar probes with a fake `fetch`; result schema/redaction; Docker argv;
  client JSON mapping; scan cleanup.
- **Fakes:** `FakeDocker` for intake/client/scan; no `docker` subprocess in the default suite.
- **Integration, opt-in:** vulnerable and safe Node fixtures; sidecar egress; cleanup.
- **No false EXPOSED:** the safe fixture is a hard gate; `*` + credentials is NOT_REPRODUCED.
- **Data:** body excerpts capped at 4 KiB; secret values redacted; results 0600.

## Edge Cases & Error Handling

| Case | Behavior |
|---|---|
| App binds only `127.0.0.1` | Sidecar cannot reach it; `UNVERIFIED`, not EXPOSED |
| CORS `*` + credentials | `NOT_REPRODUCED` (browsers reject) |
| Generic 404 | `NOT_REPRODUCED` |
| Stack trace / SQL error | `EXPOSED` |
| `/.env` 404 / 200 without secret | `NOT_REPRODUCED` |
| `/.env` 200 with secret | `EXPOSED`, value redacted |
| Cross-origin redirect | `NOT_REPRODUCED`/`UNVERIFIED`; no follow |
| Sidecar exec error/timeout | `UNVERIFIED` for that probe |
| Intake failure | no results; network/workspace cleaned |
| SIGINT | cleanup; exit 1 |
| URL target | P1 token required; `UNVERIFIED` (live probes not built) |
| Level 1/2 | exit 2 `INTENSITY_INSUFFICIENT` |

## Agent Execution Notes

- **TDD every phase.** Test first, red, implement, green.
- **Commit per phase** with the exact messages. Never commit `.venv`/temp/secret data.
- **Checkpoints:** after Phase 0 (network flags), after Phase 2 (probe verdict rules), after
  Phase 4 (cleanup), after Phase 5 (CLI).
- **Likely debugging:** Docker internal network DNS alias, sidecar mount path, `docker exec`
  JSON quoting, `urllib` redirects, Node binding `0.0.0.0`, macOS UID.
- **Ask before proceeding if:** a probe would need a write, a real third-party target, or a
  weaker network policy.
- **Do not:** add missing-auth/IDOR/DB probes, live URL probing, or claim the app is secure.
