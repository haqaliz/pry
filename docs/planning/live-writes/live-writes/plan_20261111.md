## Edge Cases

| Case | Behavior |
|---|---|
| Both confirmations + token + config | one write |
| Missing extra confirmation | exit 2, no request |
| Missing token/invalid config | exit 2, no request |
| SSRF flags on URL | exit 2, no request |
| Write 201 + verify marker | EXPOSED, signed |
| Write 401/403/404 | NOT_REPRODUCED |
| Write 2xx, marker absent | NOT_REPRODUCED |
| Write 5xx/transport | UNVERIFIED |
| No config | no write |
| Default scan | unchanged |

## Definition of Done

- AT1–AT9 pass; default suite offline; loopback integration passes.
- Live write EXPOSED signed/reported only with the extra confirmation.
- Docs state staging preference, no rollback, and the risk.
