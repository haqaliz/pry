## Phase 0: Config, probe, live scan

**Files:** `src/pry/probe/live_ssrf.py`, `src/pry/probe/live.py`,
`tests/probe/test_live_ssrf.py`, `tests/probe/test_live.py`

**Steps (TDD):**
1. Tests:
   - `validate_live_ssrf` accepts HTTPS callback with a path; rejects HTTP non-loopback,
     userinfo/query/fragment, same-origin callback, invalid endpoint/parameter.
   - `probe_live_ssrf`: SSRF 200 + callback 200 → EXPOSED; 404/404/200 → EXPOSED on attempt 3;
     404 all → NOT_REPRODUCED; SSRF 401/403/404 → NOT_REPRODUCED, no polls; SSRF 5xx/transport
     → UNVERIFIED; callback transport/5xx → UNVERIFIED; no auth/cookies; nonce unique; callback
     pair captured.
   - `scan_live(..., ssrf_config=...)` appends/signs the result; token validated first; no
     config → unchanged; same-origin callback raises before any request.
2. Implement `live_ssrf.py`, `scan_live` integration.
3. Run tests.

**Commit:** `feat(probe): prove live ssrf with a user callback`

**Commit:** `feat(cli): allow live ssrf with a user callback` and

## Edge Cases

| Case | Behavior |
|---|---|
| Callback 200 | EXPOSED |
| Callback 404 all | NOT_REPRODUCED |
| SSRF 401/403/404 | NOT_REPRODUCED, no polls |
| SSRF 5xx/transport | UNVERIFIED |
| Callback transport | UNVERIFIED |
| Missing callback/confirm/token | exit 2, no request |
| Same-origin/HTTP callback | exit 2 |
| Local + callback | exit 2 |
| Default scan | unchanged |

## Definition of Done

- AT1–AT10 pass; loopback end-to-end passes; default suite offline.
- EXPOSED signed/reported only on a callback hit.
- Docs state the poll contract, callback ownership, and one-fetch scope.
